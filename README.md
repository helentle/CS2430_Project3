# CS2430_Project3
Run instructions: Run Main.java as a Java Application to see knapsack problem subset results


---------------------Class Overview-----------------------
BruteForce.java
- Recursively generates all possible subsets and returns the top three that meet requirements

Comparison.java
- Outputs results of the greedy strategies, brute force method, and which strategies matched the optimal subset

DynamicProgramming.java
- Contains commented pseudocode for a dynamic method for finding the best subset

Experiment.java
- Creates an experiment object for each of the experiments

GreedyStrategies.java
- Contains three greedy methods where the experiment list is sorted by highest rating, lightest, and then rating to weight ratio

Main.java
- Runs the results for the greedy strategies and brute force results and outputs the top three brute force subsets and the print summary

Results.java
- Stores the outputs of the different subset calculating algorithms
